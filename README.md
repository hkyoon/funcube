# 루미큐브

브라우저에서 하는 루미큐브 웹 게임입니다. HTML 파일 하나로 되어 있습니다.

- 혼자 연습: 컴퓨터 1~3명과 대전 (진행 상황은 브라우저에 저장)
- 방 만들기 / 초대: 4자리 방 코드와 초대 링크로 최대 4명이 함께 플레이, 빈 자리는 컴퓨터로 채움
- 규칙: 그룹·런 자동 판정, 조커, 첫 등록 30점, 테이블 재배치

방 만들기와 초대 기능은 claude.ai 아티팩트의 공유 데이터베이스(`window.claude.use("db")`)를 사용하므로 claude.ai 안에서 열 때만 동작합니다. 그냥 파일로 열면 혼자 연습하기만 쓸 수 있습니다.
